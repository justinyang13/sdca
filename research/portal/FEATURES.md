# SDCA Portal — feature inventory (from the old register.sandiegochineseschool.com)

Sources: 28 redacted screenshots (staff/secretary view + parent forms) and 3 PDFs (Portal User Manual v1.4, Online Registration User Guide, Registration Notice 2026-27).
No personal data is stored in this file. Field names are exact (EN / 中文 as shown).

## 1. Who logs in (user types) and what each sees
| Type | Evidence | Landing page |
|---|---|---|
| **Staff – Admin** | only admin account exists; full menus | admin dashboard: everything + Role & Permission management |
| **Staff – Secretary / Registrar** | "Secretary Resources" block on the home page: *List All People*, *班級人數清單 / Download Class Roster PDF*, *Download Volunteer List CSV*, *Download Student List CSV*, register / volunteer buttons, People list, family + person edit, manual transactions | secretary dashboard |
| **Staff – Principal** | PDF: Principal is the contact for non-registration questions | principal dashboard (read-mostly: classes, rosters, staff, reports) |
| **Staff – Teacher / Instructor** | Manual p.28: "Instructor Resources" shown before personal info, with a *student list* button per class | "Instructor Resources" + class list |
| **Staff – Accountant / Treasurer** | `accounting/manual_transactions` (new / show), registration payment entry | finance dashboard |
| **PTA / Volunteer Coordinator** | volunteer list CSV, job list, sign-ups | volunteer dashboard |
| **Parent** | Home = Person + Family + Student Information; Register; Volunteer Sign Up; Transaction History; Change Password | family home |
| **Room Parent** | Manual p.28 "Instructor / Room Parent": same Instructor Resources + class list (class header shows *Room Parent*) | family home + class list |
| **Volunteer** | volunteer job sign-up (parents choose up to 3 jobs; PTA assigns) | volunteer home (my jobs, directory of jobs) |
| **Student (Credit only)** | credit students are 6th–12th grade; no student screens were captured | student home (own class, schedule, transcript hand-off) — scope to confirm |

A **person can hold several types at once** (parent + staff + room parent). The old site is Rails-style, so one `users` row per login and one `people` row per human.

## 3. Business rules found (must be configurable data, not code)
- School year **2026-2027**; classes meet Sundays: Preschool 1:30–4:00, Immersion/Bilingual 1:30–4:30, High-School Credit 1:30–5:45 (+25 h of field trips).
- Fees per school year: Registration Fee **$50**/student (waived when paid by last day of school; **Early Reg Discount** if registered by 5/17), Tuition **$930** (Preschool/Regular/Bilingual, 30 weeks, books included) or **$1,195** (Credit, 32 weeks, books not included), **$100 off per student from the 3rd sibling**, faculty/board **10% off** (reimbursed in 2nd semester), Misc **$100**/student, **Service Fee $100**/family (fully refundable after volunteer duty, refunded in Scrip), Scrip Deposit / Scrip Purchase amounts.
- **Withdrawal** refund schedule: before 8/31 full; 8/31–week 1 $100; week 2 $110; week 3 $120; week 4 $130; week 5 $140; week 6+ none. Written application.
- Payments: **cash or check only**, no cards; registration is "complete" only when staff enter the payment; parent then gets an email; class placement visible one week before school starts.
- Volunteering: up to 3 prioritised jobs, "TBD" allowed, PTA assigns; preschool-parent-reserved jobs.
- Credit classes: need middle/high-school counselor info each year; Poway district off-campus language form.
- Preschool: child must be 4 by 8/31; parent presence required. Under-5 waiver.
- Returning families must NOT create a new account (keeps history, sibling discount, single service fee).
- New-student-only questionnaire (Chinese background).
- Directory opt-in (List in School Directory Y/N).
- Registration receipt carries tax ID.
- Exports: class roster PDF, volunteer CSV, student CSV (Excel/UTF-8 notes).
